## ▶️ How to Run

### 1️⃣ Clone the Repository

```bash
git clone YOUR_REPOSITORY_LINK
```

### 2️⃣ Open the Project

Open the cloned project using:

* IntelliJ IDEA
* VS Code
* Any Java-supported IDE

### 3️⃣ Compile the Program

```bash
javac FileName.java
```

### 4️⃣ Run the Program

```bash
java FileName
```
