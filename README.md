## ▶️ How to Run Java Programs

1. Clone this repository:

   git clone YOUR_REPOSITORY_LINK

2. Open the project in IntelliJ IDEA or VS Code.

3. Open the Java file you want to run.

4. Compile the program:

   javac FileName.java

5. Run the program:

   java FileName
